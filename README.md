Weather/Time:

-Daytime: no effects.
-Heavy Rain: Slow speed for all attackers by 10%, defenders in flooded trench 20%.
-Snow: slow both attackers/defenders by 10%, and shoot 10% slower.
-Snow Blizzard: lowers attackers/defenders range -1, move -10% slower and shoot slower.
-Sand Storm: lowers attackers/defenders range -1, move 10% slower and shoot slower by 10%.
-Fog: removes line of sight for both attackers/defenders, depending on fog coverage.
-Night: line of sight reduced by 50% when dark, (effect removed by light).

Mission maps:

-Beach: horizontal is map smaller due to beach (creating more compact and intense map).

-Forest: trees block from build trenches in certain tiles (can also catch bullets)
